# ノリ打ち配分の丸め単位

## 目的

ノリ打ちで差をつける配分を選んだ際、250円など受け渡しに不向きな端数が発生しないようにする。

## 丸めルール

- 均等配分: 500円単位
- 少し差をつける: 1,000円単位
- 大きく差をつける: 1,000円単位

配分後の目標収支合計はグループ全体の収支と必ず一致させる。丸めで生じた差額は、配分モードが意図する成績順を保ったまま1単位ずつ調整する。

## 受け渡し

受け渡し額は目標収支と実績収支の差から計算する。入力額が既定単位に揃っている場合、均等配分では500円単位、差をつける配分では1,000円単位となる。

100円単位などの入力が含まれる場合も、アルゴリズムは総額を失わない。完全に1,000円単位へ揃えられない端数がある場合に限り、最終調整へ残額を集約する。

## 非対象

UI、メンバー入力、配分モードの重み、交換計算は変更しない。

## 検証

- 均等配分の既存500円受け渡しを維持する。
- 差をつける2モードで250円単位が発生していたケースを1,000円単位へ丸める。
- 目標収支の合計がグループ収支と一致する。
- 支払総額と受取総額が一致する。
