# 交換目安ツール — スマホUI軽微改善

## 目的

既存のスマホ向け画面構成、操作順、機能を維持したまま、視認性と画面の密度設計を整える。
Hallmark監査で採用された指摘だけを修正し、PC向けの新レイアウトや大規模な構造変更は行わない。

## 対象

- 対象画面: 交換、ノリ打ち、管理、条件シート、電卓シート
- 対象幅: 320px、375px、414px
- 主な変更ファイル:
  - `index.html`
  - `tokens.css`（新規）
- 削除ファイル: なし

## 維持する機能

以下のDOM上の接続点、保存形式、イベント処理、計算ロジックは変更しない。

- 持ち玉入力と電卓
- 交換率・景品の選択
- 目標レールと前後候補
- 交換額・景品のブラー初期状態
- 結果サマリーと候補表の個別表示切替
- 条件保存、プリセット適用
- 保存条件の並べ替え、編集、削除
- ノリ打ち計算
- アプリ更新とService Worker
- `localStorage`の既存キーとデータ形式

`id`、`data-sensitive-*`、`data-apply-preset`など、既存JavaScriptが参照する属性は維持する。

## 採用する視覚変更

### 1. Card-in-card

外側パネルと内側カードの二重の囲いを減らす。
入力、条件、結果は独立した機能面として残し、不要な外枠は罫線と余白へ置き換える。
条件シートなど、浮遊を表す必要がある面だけに影を残す。

### 2. Pure black / pure white

純白と黒に近い色の直接使用をやめ、既存の青緑に寄せた紙色、面色、文字色を使用する。
背景、面、罫線、アクセント、危険色、フォーカス色を意味ベースのトークンとして定義する。

### 3. Single-font flattening

用途を次の三つに分ける。

- 見出し: `BIZ UDPGothic`を優先
- 本文・操作ラベル: 既存の日本語システムフォント
- 玉数・金額・交換率: `ui-monospace` / `Cascadia Mono`

外部フォントのダウンロードは追加しない。

### 4. Mid-render token improvisation

色、書体、余白、角丸、影、フォーカスリングを`tokens.css`へ集約する。
変更対象のCSSでは、個別のhex、`rgb()`、`rgba()`、直接の`font-family`指定を追加しない。

既存値のうち今回触れない箇所は、機械的な全置換を行わない。
視覚差分の対象になった値からトークンへ移す。

### 5. Hover-only affordances

前後の目標ボタンを通常状態でも読める濃度にする。
ホバーを前提にせず、タップ可能なラベルと数値を常時表示する。
無効状態は透明度だけに依存せず、操作不可属性と文字色を併用する。

### 6. Tabular data without tabular-nums

以下に`font-variant-numeric: tabular-nums`を適用する。

- 持ち玉
- 目標レール
- 交換額と必要玉数
- 候補表
- ノリ打ちの投資、回収、収支、受け渡し
- 管理画面内の金額

### 7. Every section padded the same

機能ごとに密度を変える。

- 入力: 操作しやすい余白
- 目標レール: 高さを抑え、横方向の読み取りを優先
- 条件: コンパクト
- 結果: 数値の周囲に余白を確保
- 管理: 一覧性を優先して密度を上げる

画面のDOM順は変更しない。

### 8. Side-stripe card

太い左罫線の通知表現を廃止する。
「あと何玉」の通知は、薄いアクセント面と上罫線で表現する。
警告状態も同じ構造のまま色トークンだけを切り替える。

## ブラー表示

ブラー機能は維持する。
現行の`.sensitive-scope.blurred`と`.sensitive-value`の制御を残す。

透明な全面タップ領域は、機能を変えずに「金額と景品を表示」という見えるボタンとして表現する。
結果サマリーと候補表の`data-sensitive-group`は統合せず、個別切替を維持する。

## 条件保存

交換画面内の「この条件を保存」、条件シート、管理画面の保存条件一覧を維持する。
保存フォームは通常時は折りたたまれたままとし、見た目だけを新トークンへ合わせる。

保存、適用、並べ替え、編集、削除のイベント処理とUndoは変更しない。

## アクセシビリティ

- 主要操作のタップ領域は44pxを目安にする
- フォーカスリングは即時表示し、アニメーションしない
- 文字付きボタンは一行表示を維持する
- 色だけで選択・無効・危険状態を表現しない
- 画面切替ボタンには既存動作を維持したまま`tablist`、`tab`、`aria-selected`を追加する
- `prefers-reduced-motion`を尊重する

## 実装境界

計算処理を含む`app-core.mjs`は変更しない。
`index.html`内のJavaScriptは、タブARIA同期など視覚変更に必要な最小範囲を除いて変更しない。
HTML要素を移動する場合も、既存IDとイベント接続を維持する。

## 検証

### 自動テスト

- `node --test app-core.test.mjs`

### ブラウザ確認

- 320px、375px、414pxで横スクロールがない
- 交換、ノリ打ち、管理の切替
- 持ち玉入力と計算結果更新
- 結果サマリーのブラー切替
- 候補表のブラー切替
- 条件保存と再適用
- 保存条件の編集、並べ替え、削除
- 条件シートと電卓シートの開閉
- キーボードフォーカス表示

## 対象外

- PC専用レイアウト
- 画面順序の変更
- 計算ロジックの変更
- 保存形式の変更
- 新しいアニメーション
- 外部フォント、アイコンライブラリ、画像素材の追加
